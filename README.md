# Übungsaufgaben: 4diac Trainingslösungen (4.2)

Ausgelagerte Übungsaufgaben-Musterlösungen aus
[visual-programming-languages-docs](https://github.com/Meisterschulen-am-Ostbahnhof-Munchen/visual-programming-languages-docs)
(Wiki 4 „Visuelle Programmiersprachen: Low-Code"), als eigenes Wiki **4.2**.

Analog zu [Wiki 4.1](https://github.com/Meisterschulen-am-Ostbahnhof-Munchen/4diac-library-reference-docs)
(Bibliotheken-Referenz): `Uebungen/` war mit ~1.300 Dateien pro Sprache die
zweitgrößte Content-Gruppe im Hauptwiki. Die Auslagerung ist hier präventiv
(nicht akut nötig wie bei den Bibliotheken), damit das Hauptwiki nicht in
ein paar Monaten wieder gegen das ReadTheDocs-Zeitlimit läuft.
